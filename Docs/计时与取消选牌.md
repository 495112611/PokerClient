# 计时与取消选牌

客户端和服务器需要一起重新编译运行。倒计时和空白点击组件由 `BattlePanel.OnShow()` 自动创建，不需要手动修改或挂接预制体。

## 规则

| 阶段 | 时间 | 超时操作 |
| --- | --- | --- |
| 叫地主 | 15 秒 | 自动不叫 |
| 抢地主 | 15 秒 | 自动不抢 |
| 跟牌 | 30 秒 | 自动不出 |
| 必须领出一手牌 | 30 秒 | 自动出最小单牌 |

计时牌显示在当前操作玩家附近，最后 5 秒变红。三人均不叫时服务器重新发牌；游戏结束或玩家离开房间时停止计时。

点击牌桌空白区域，会清空选牌列表、恢复抬起的牌和牌的颜色。点击卡牌或操作按钮不会触发空白取消。原来的拖动选牌方式保留。

## 代码入口

- 服务器 `Room/Room.Turns.cs`：阶段、计时、超时操作和回合轮换。`BidSeconds`、`PlaySeconds` 是时间配置。
- 服务器 `EventHandler.OnTimer()`：在网络主循环中检查各房间的计时。
- 两端 `Proto/Battle/MsgTurnState.cs`：服务器下发当前玩家、阶段、回合编号和剩余秒数。
- 客户端 `BattlePanel.OnMsgTurnState()`：刷新操作按钮及计时 UI。
- 客户端 `TurnTimerView.cs`：倒计时的位置、文字、颜色和进度条。
- 客户端 `BlankClickCatcher.cs`、`CardUI.ClearSelection()`：判断空白点击并复原选牌状态。

客户端只显示服务器每秒下发的数值，不自行执行超时操作。点击请求带上 `turnId`，服务器校验当前玩家、阶段和回合编号，避免超时后到达的旧点击推进新回合。原来的客户端 `round` 请求不能再推动服务器轮换。

## 验证

在 PokerServer 目录运行：

```sh
dotnet run --project Tests/TurnTimerTests.csproj
```

测试使用可控时钟覆盖到期前、到期瞬间、迟到请求、连续超时、重新发牌、结束停表以及原先的抢地主顺序。
